# XYBarRenderer

Responsabilidade

- Renderer para barras em coordenadas XY (intervalos em X/Y), usado por plots XY que exibem barras.

Resumo para Javadoc a aplicar na classe fonte

/**
 * Renderer que desenha barras em coordenadas XY, suportando intervalos
 * horizontais/verticais definidos por `IntervalXYDataset`.
 */

Pontos a documentar

- Dependência de `IntervalXYDataset` e mapeamento de intervalos para pixels
- Como lidar com overlaps entre barras de séries diferentes
