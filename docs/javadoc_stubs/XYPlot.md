# XYPlot

Responsabilidade

- Implementação de `Plot` para dados XY: gerencia múltiplos datasets, eixos X/Y e renderers para gráficos de séries XY.

Resumo para Javadoc a aplicar na classe fonte

/**
 * Plot especializado para dados X/Y. Suporta múltiplos datasets, múltiplos

 */
