# PlotRenderingInfo

Responsabilidade

- Estrutura de dados que armazena metadados gerados durante a fase de desenho do `Plot` (usada para entidades, tooltips e mapear coordenadas de pixel para dados).

Resumo para Javadoc a aplicar na classe fonte

/**
 * Contém informações coletadas pelo `Plot` enquanto desenha, como áreas de
 * dados, tabelas de entidades e informações de subplots.
 */
